### Document and Image Handling

* In the **Running module**, please refer to how documents and images are currently stored and handled during document uploads.
* I want the same functionality to be available within each **section**.
* Users should be able to **upload a document or copy and paste an image/document directly into a section**.
* When a document or image is copied and pasted, it should be inserted **only within the selected section** and should not appear in any other section.

### Chapter and Section Structure

* All documents, images, and additional attachments should be maintained **chapter-wise and section-wise**.
* Content added to one section should remain associated with that specific section.
* Moving or reorganizing sections should preserve their respective content and attachments.

### Section Deletion

* Whenever a user attempts to delete a section, a **confirmation popup** should appear before deletion.
* The popup should clearly inform the user that the section is being deleted and require confirmation before proceeding.
* Deleted sections should follow the previously defined **7-day archive period** before permanent deletion.

### Additional Section Attachments

* Each section should have an option to **attach additional documents**.
* Supported attachments should include, at minimum:

  * Images
  * PDF files
  * Other relevant document/file formats
* These attachments are **additional content** and should not replace or overwrite the main section content.
* Attachments should be stored and displayed **within their respective chapter and section**.
