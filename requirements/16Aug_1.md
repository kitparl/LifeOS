# Production-Ready Angular Markdown & Multi-Language Code Workspace

## Objective

Integrate a production-ready, reusable **Markdown Writer + Markdown Preview + Multi-Language Code Editor + Code Execution Workspace** into the existing Angular application.

This must be built as a reusable feature/module/component system, NOT as a one-off page.

The feature will eventually be reused for:

* Documentation
* Articles
* Blog/content management
* Tutorials
* Lessons
* Coding exercises
* Assignments
* Technical documentation
* Notes
* AI-generated content
* Interactive programming examples

The first implementation should establish the complete editor infrastructure so additional use cases can be added later without redesigning the editor.

---

# 2. TECHNOLOGY REQUIREMENTS

Use a free/open-source stack.

Primary editor:

* CodeMirror 6

Required packages:

* `codemirror`
* `@codemirror/lang-markdown`

Add CodeMirror language packages only where needed.

For Markdown rendering, use a mature open-source Markdown parser.

For sanitization, use a mature open-source HTML sanitizer such as DOMPurify.

Do not introduce a paid editor SDK.

Do not make the application dependent on a paid editor subscription.

Keep the architecture compatible with commercial use, while checking the license of every dependency added.
